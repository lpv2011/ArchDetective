# ArchDetective
Scanner that aims to bridge a crucial gap in current software compatibility tools.
I tried two different approaches with this:
  1. checking for discrepencies using PyPI (Download of package to local machine required) refer: pypi_wheel_scan.py
  2. checking for discrepencies using APT (Advanced Package Tool) on Debian-based Linux distributions (No download required) refer: apt_cache_scan.py
